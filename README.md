- 🚀 **Exploring Aerospace & Energy:** Created the [Shaggar Solar Array Optimizer](https://shaggar-solar-array-optimizer.vercel.app) to calculate and optimize solar yields.
- ⚛️ **Physics & 3D Simulations:** Modeled linear and angular mechanics in interactive 3D using **Three.js** and **React**.
- 🤖 **AI & Intelligence:** Developed NLP-assisted chatbots ([Science-Bot](https://github.com/Nati874/Science-Bot), [MIBOT](https://github.com/Nati874/Telegram-bot-MIBOT-)) and algorithmic logic platforms like [AI Court System](https://github.com/Nati874/AI_Court_System).
- 💚 **Community & Impact:** Built [EFOY-V2](https://github.com/Nati874/EFOY-V2) (a digital mental well-being platform) and [Math Camp](https://math-camp-kappa.vercel.app) (gamified STEM learning).
